## Notes for picking a project

- Winning a sponsor's category earns a 1:1 founder chat with most sponsors, so using a sponsor's product well is the path to a category prize.
- Most sponsors are agent infrastructure (cloud, access control, tracing, memory, people data). A voice agent built on ElevenLabs can combine several of them.
- Fiber AI runs a Slack workspace for the event for updates, account setup and questions. The invite link is in their email.
